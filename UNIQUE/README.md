## 參考及適用版本

[Microsoft Support：UNIQUE function](https://support.microsoft.com/en-US/Excel/functions/unique-function)。適用 Microsoft 365、Excel 2021／2024 等支援 UNIQUE 的版本。

`=UNIQUE(array,[by_col],[exactly_once])`：省略第 2 項時比較列；第 2 項 TRUE 比較欄。第 3 項預設 FALSE，保留不同項目各一個；TRUE 則只保留恰好出現一次的列或欄。方括號表示可省略，輸入時不必加入。

本課未涵蓋沒有符合項目時的 #CALC!、跨活頁簿動態陣列限制等進階情況。
